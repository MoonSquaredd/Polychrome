# Polychrome
by: lovenus

Version: 0.2.1

A mod for GGXXACPR (Steam) aiming to add many funcitonalities around colors in the game.

!! REQUIRES Gear Loader !!

Current Additions:
- Allows editing several hardcoded colors from the game without needing to re-open it every time.
- A toggle for Eddie's glow effect.
- Fixes for fire and lightning cycling palettes.
- Allow changing palettes in-game.

Instructions:
- Extract the .zip to your GGXXACPR root folder.

- Colors can be edited in "mods/Polychrome/colors.txt" and reloaded at any time through the in-game mod settings. Make sure to back it up whenever updating this mod!

- Additional instructions in the colors.txt file.
